# APE 06: Arreglos y Listas

**Universidad Técnica de Ambato**
**Facultad de Ingeniería en Sistemas, Electrónica e Industrial**
**Carrera de Software**

Este repositorio contiene el desarrollo de la Guía Práctica (APE 06) correspondiente a la asignatura de **Algoritmos y Lógica de Programación**. El proyecto se centra en el manejo de arreglos y listas dinámicas para la manipulación de datos.

## 🎯 Objetivos de la Práctica
* Implementar las estructuras de datos `ArrayList` y `LinkedList` en Java (y sus equivalentes `vector` y `list` en C++) mediante la codificación de ejercicios prácticos.
* Diseñar algoritmos que apliquen operaciones de gestión de datos (Crear, Leer, Actualizar, Eliminar - CRUD) dentro de listas dinámicas.
* Comparar el rendimiento y las limitaciones funcionales entre los arreglos estáticos tradicionales y las listas dinámicas.

## 📝 Listado de Ejercicios Desarrollados

El proyecto consta de 10 ejercicios funcionales resueltos tanto en C++ como en Java:

1. **ArrayList I - Nombres de Estudiantes:** Creación de una lista dinámica para almacenar e imprimir cadenas de texto.
2. **ArrayList I - Notas:** Almacenamiento de valores decimales para sumar sus valores y calcular el promedio final.
3. **ArrayList I - Registro y Búsqueda:** Creación de una lista de productos y desarrollo de una búsqueda iterativa de coincidencias.
4. **ArrayList II - Menú CRUD:** Implementación de un bucle interactivo que permite Agregar, Leer, Actualizar y Eliminar elementos de la lista.
5. **ArrayList II - Nombres y Notas (POO):** Aplicación de Programación Orientada a Objetos creando una clase `Alumno` y almacenando objetos dentro de una lista.
6. **ArrayList II - Sistema de Inventario:** Iteración sobre una lista de objetos `Producto` para calcular el patrimonio total (cantidad * precio).
7. **Arreglo vs ArrayList (Comparación):** Demostración práctica de cómo un arreglo primitivo tiene un tamaño inmutable, mientras que un ArrayList puede crecer dinámicamente.
8. **Arreglo vs ArrayList (Inserción):** Uso de bloques `try-catch` para demostrar cómo forzar el límite de un arreglo nativo genera una excepción, a diferencia de las listas dinámicas.
9. **LinkedList - Manipular Turnos:** Uso de nodos doblemente enlazados para demostrar la eficiencia en operaciones de cabecera al eliminar el primer turno y desplazar el siguiente.
10. **LinkedList - Fila de Atención:** Bucle condicional que simula una fila, despachando a los clientes hasta vaciar la lista.
